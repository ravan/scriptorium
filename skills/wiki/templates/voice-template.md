## HOW TO USE THIS DOCUMENT (ANTI-OVERFITTING GUIDE)

This document captures taste. It is NOT a checklist to apply rigidly.

- **Spirit over letter**: a piece using 3 tendencies naturally beats one forcing in 10.
- **Labels**: HARD RULE = never violate. STRONG TENDENCY = ~70-80% of the time. LIGHT PREFERENCE = context decides. Unlabeled = LIGHT PREFERENCE.
- **Context matters**: a LinkedIn post is not a blog is not an internal note; let the format bend the patterns.
- **Natural variation**: real writers are not perfectly consistent. Vary openings; let content dictate structure.
- **Litmus test**: "Does this sound like something {{NAME}} would actually write, or like an AI trying hard to imitate them?" If forced, pull back.
